Synthetic data. Every record here is computer generated by this repository; none of it comes from a real patient. The extraction backend is a configurable rule and lexicon baseline, not a trained clinical NLP model, and coded terms in the catalogue are illustrative placeholders rather than licensed dictionary content.

A blank is not a value. Each source record carries a collection state per field, and the state is what a rule is allowed to read. Nothing here is merged or overwritten: this is the grain the study actually collected.

Highlighted ranges are the spans backing extracted values. Hover to see which field each supports. A populated field with no span is a defect, not a caveat.

The deterministic path fills what the CRF settled; the model path is asked only about what it left unresolved, and may answer abstained. Neither assigns an evidence state.

An episode is derived above the records, never in place of them. Where the linkage rule is a judgement call the episode is flagged, not resolved, and the flag travels into every downstream verdict.

Concept and missingness

A definition may not read not_collected_by_protocol or not_applicable_gated as evidence of absence; the loader rejects one that tries. Treatment action is an attribute of the episode and appears in no rule.

Editable rule parameters

Editing these builds a candidate next version. The frozen definition on disk is never touched.

Compare two versions

The comparison is executed, not textual: both versions run against the same snapshot and the answer is the episodes each one claims. A scope is required — this is for evidence reuse within a stated question, not for sweeping a programme to audit past choices.
