Synthetic data. Every record here is computer generated by this repository; none of it comes from a real patient. The extraction backend is a configurable rule and lexicon baseline, not a trained clinical NLP model, and coded terms in the catalogue are illustrative placeholders rather than licensed dictionary content.

Anatomical location can live in a standard qualifier, a sponsor-defined supplemental variable, the investigator's own words, a linked comment — or nowhere. Which one applies is a per-study collection decision, and the route is part of the fact: every value below says which variable it came from and by which method.

Method

  1. mask the structured variable from the extractor
  2. run the model path over the text alone
  3. normalize both sides to the concept catalogue
  4. compare the extracted value against the masked one

Adjudication queue

Disagreements, low-confidence predictions, and a random sample of agreements. The sample is not optional: without it you only ever inspect failures and can never estimate the comparator's own error rate.

Four verdicts. not_ascertainable is not a negative: a required attribute was never recorded and cannot be recovered, so nobody can evaluate the rule — not the system and not a reviewer.

Compare two versions

Executed, not textual: both versions run against the same snapshot. A scope is required — this is for evidence reuse within a stated question, not for sweeping a programme to audit past choices.

Cohort membership is decided by normalized attributes and a definition's verdict — no embedding is consulted for it. Discovery is where semantic search earns its place: finding modifiers the value space does not cover yet, so a person can decide whether to extend it.
